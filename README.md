# Club Management Website  

This is a **club management system** developed by **Hadi Chouaieb**. The project is built using **React** for the frontend and **Node.js** for the backend. It provides a user-friendly platform to manage clubs efficiently.  

---

## Key Features  

- **React**: Dynamic, responsive user interface.  
- **Node.js**: Powerful backend server for API handling.  
- **Club Management**: Easy-to-use tools for creating and managing clubs, members, and events.  
- **Responsive Design**: Works seamlessly on desktops, tablets, and mobile devices.  (not the best design)
